# Pika Dots 0.11.0

Latest hackathon build with Focus, Chill, Explain, and Actions. Actions replaces the Outreach name and instructions with general browser tasks, including navigation, research, forms, and follow-up task notes. Existing custom companion skills are preserved when loading saved companions.

Includes the current purpose-aware Focus checks, browser tab integration, voice input and cat sounds, supervision API selection, attachment/reply UI updates, and minimal character design sheets in the source repository.

Validation: 69 automated tests passed; five optional live tests skipped. Universal signed build and package checked. This release does not claim end-to-end verification of live API calls, Chrome automation, microphone permissions, or Intel runtime behavior.

Requires macOS 14+. Developer ID signed, not notarized. Unzip the app, move it to Applications, and add your own API key in Settings. Review the companion skill and approval mode before using browser actions. Keys and personal companion data are not included in the download.
