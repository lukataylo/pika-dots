Smaller UI, larger cats, shorter communication.

- Removed the expanded response/error box from attached windows.
- Responses, reminders, and errors now use native macOS notification banners. If notifications are disabled, a short five-second corner banner is used instead.
- All notification text is capped at 14 words and 100 characters; model replies are also instructed to stay within 14 words.
- Cats are twice as large: 40-point views on the shelf, during dragging, and when attached.
- Purpose input appears only when explicitly opened, and collapses after submitting a task.
- Settings includes notification status, Enable, Test, and macOS notification settings controls.

Universal macOS 14+ test build, Developer ID signed, not notarized. Allow notifications when macOS asks. No API keys bundled.
